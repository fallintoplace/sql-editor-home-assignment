# ClickStudio documentation

This repository is an interview project, so the documentation is split by reviewer intent rather than by implementation chronology.

## Start here

1. [README](../README.md) - quickest way to run the project and see the main features.
2. [Engineering decisions and tradeoffs](ENGINEERING-NOTES.md) - the most useful technical discussion for a code review or interview.
3. [Project scope](PROJECT-STATUS.md) - what is implemented and what is intentionally outside the project boundary.

## Reference

- [Setup and implementation reference](CLICKSTUDIO.md) - detailed setup, execution behavior, imports, persistence, assistant behavior, limits, and operational details.
- [Product roadmap](product-roadmap/) - optional product exploration and future ideas. It is not required to understand the submitted implementation.

The README and engineering notes are the intended review path. The longer reference documents exist for details, not because every section is expected interview reading.
